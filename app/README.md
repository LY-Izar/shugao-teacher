***REMOVED******REMOVED*** 设计语言

刻意避开「大圆角卡片 + 柔和投影 + 渐变紫 + 填充图标」那套通用观感。

| 维度 | 做法 |
| --- | --- |
| 分隔 | **发丝线**（1px）为主，几乎不用投影 |
| 层次 | 画布 → **悬浮侧栏** → 栏内分区块，三层分明。侧栏四周留 14px 空隙让画布露出来，
自带表面与四层叠加投影（内侧镜面高光 → 贴边细影 → 中程投影 → 远场柔影），
所以它读起来是**浮在界面之上的一层**，而不是贴在背景上的侧边条 |
| 圆角 | **2 / 4 / 6**，只有底部浮层用 10 |
| 图标 | **全部自绘**线条 SVG：24×24 网格、1.6 描边、圆头圆角、无填充 |
| 数字 | 等宽数位（`tabular-nums`）保证不跳动；**不用等宽字族**，避免 Consolas 的斜杠零把学号 `10` 显示成 `1Ø` |
| 背景 | 极淡的方格网，顶部径向遮罩淡出，提供科技感但不抢内容 |
| 主色 | 电蓝 `***REMOVED***0B5CF0`；青色 `***REMOVED***00B0C6` 仅用于扫描/在线等点缀 |
| 动效 | 路由切换页面过渡、底部导航**液态胶囊滑动 + 拉伸回弹**、按钮真实坐标波纹、扫描线、步骤勾选、线条自绘、时钟跳秒；全部尊重 `prefers-reduced-motion` |
| 液态玻璃 | 只用在**浮在内容之上**的元素：移动顶栏、底部导航、Toast、取景框提示条、名单表头（行会从下面穿过去）。内容卡片一律实心 —— 玻璃用多了会糊，正文也会失焦 |
| 磨砂 | 移动端底栏是**磨砂玻璃**而不是单纯模糊：`blur(26px) saturate(190%)` 之上再叠一层 3px 间隔的极细白色噪点（`::before`，排在子元素之前所以不会盖住图标），模糊才有质地 |
| 选中态 | 底栏选中项是一个**液态玻璃胶囊**：实测 tab 位置后滑过去（`cubic-bezier(.34,1.32,.5,1)`），切页时用 Web Animations 打一段 `scaleX 1 → 1.16 → 0.97 → 1` 的拉伸回弹，胶囊内缓慢游走高光，图标再弹一下 |
| 文案 | 面向 45 岁以上教师：大字号、少层级、明确说人话 |

设计令牌集中在 `src/index.css` 的 `@theme` 与 `@layer components`。

***REMOVED******REMOVED******REMOVED*** S1 · 班级与花名册

- 账号登录与教师身份（学科 · 学校）
- 班级创建、编辑、删除；当前班级上下文切换
- 学生名单：增删改、转班、转出保留（不物理删除）
- **拍照录名单**：取景 → 识别（扫描线 + 四步进度）→ **逐行可改的校对页** → 导入
- **粘贴导入**：自动解析学号与姓名两列，支持 Excel / 群消息格式
- **名单体检**：缺号、重号、重名、非数字学号 —— 序列连续性检查
- 数据导出（JSON）与清空

***REMOVED******REMOVED******REMOVED*** S2 · 作业档案与收缴

- **练习册模板**：作业21 = 1–6 题、作业22 = 1–8 题…… 建过一次永久复用。
  **题号结构来自模板，不依赖任何图像识别** —— AI 从必经环节降级为加分项
- **作业档案**：名称、题目数量、布置班级、日期（默认前一天）；支持"按上次新建"
- **收作业查缺**：拍一摞作业的侧面识别已交学号 → 与花名册比对得出未交名单
- **序列自检**：识别结果做重复号 + 跳号校验，并把**重复号与相邻跳号配对**，
  直接推断出「很可能是把 29 号读成了 28 号」——把"识别失败"变成"可执行的修正提示"
- **只记例外**：登记表默认全班已交，教师只标未交/迟交；识别结果可随时手工修正
- 未交名单单独成块，可直接用于催交

> 设计上的一条硬规则：**识别只是加速器，永远不会卡住流程**。
> 无论识别成功与否，手工登记通道始终可用。

***REMOVED******REMOVED******REMOVED*** S3 · 快速批改录入

- **默认全对，只点错的** —— 一次作业 45 人里错 11 个就只点 11 下
- **题号就地展开**：点学号后，题号面板**直接在该学生正下方展开**，手指不用离开这一片区域。
  （最初做成固定底部面板，实测"点完还得滑屏"——面板离手指太远，还挡住了名单，已改）
- 展开的题号若在视口外，会**自动滚入可见范围**
- **双击题号 = 直接拆出 (1)(2)**，不弹任何确认框；题号格里的 **+** 继续加小题
- **长按题号 = 小题设置**：减少小题数或取消小题 —— **取消需要确认**，
  并明确提示"已记录的小题对错会被清除"
- **已确认 / 未查看 两态**：展开过题号列表才算确认。完成批改时提示"还有 N 人未确认"，
  避免把「漏点」统计成「做对」
- **按题模式**：先选一道题再点做错的学生，某题错的人特别多时更快
- **完成批改**：用时 / 人数 / 错题数 / 错误率的克制反馈，并直接给出讲评重点与分档建议
  （错误率 30–70% 优先精讲；<10% 建议个别辅导，不占课堂时间）

***REMOVED******REMOVED******REMOVED*** S4 · 逐题统计与改错呼叫

**作业情况页**
- 收缴概览 + 批改完整度提示（不完整时明确说"错误率可能偏低"）
- **逐题错误率条形图**，按讲评价值分档着色：
  个别辅导（<10%）· 点到即止（10–30%）· **优先精讲（30–70%）** · 精讲 + 查前置（70–90%）· 重点讲 + 回看设计（>90%）
- **点一行就地展开该题错的学生名单**（学号 + 姓名），不用跳页
- 讲评建议按"值得讲的程度"排序 —— 不是简单按错误率倒序，
  所以 **58% 会排在 76% 前面**（30–70% 区间讲评价值最高）
- 关注名单：错得最多的学生；统计口径可展开查看

**改错与一键呼叫**
- **默认不预选**，按**错题数从多到少**排序，一次挑 3–8 人；**单次上限 8 人**
- 支持**按题号筛选**（"第 5 题错的人都来"）—— 面批同一道题效率最高
- 已叫过的学生**标灰并显示状态**，不会重复叫
- 播报文案实时拼接：`请 33 号、42 号、28 号，到物理老师办公室。物理老师叫你带上作业本。`
  —— 地点**按学科算**（语文老师默认就是「语文老师办公室」），教师随时能改；
  自定义后缀限 30 字（这句话会公开放音）
- **播报学号而不是姓名**：教室里其他班学生路过时也会听到
- **教室端在线状态**：离线时会明确提示"学生很可能听不到"，而不是默默发送
- **发送前可预览教室端**：深色全屏效果 + 置顶小窗示意，先看清再发
- **状态追踪**：已叫 → 已到 → 已订正，点一下推进；支持"再播一遍"
- 呼叫记录页跨作业汇总，**不做被叫次数排行**（一旦可比就会变成压力工具）

***REMOVED******REMOVED******REMOVED*** S5 · 教室端（`/classroom`）

**一个重要的更正**：早期方案里我写过"浏览器做不到强制置顶，所以教室端必须做成 exe"。
**这个结论是错的** —— Document Picture-in-Picture API（Edge / Chrome 116+）可以开出一个
**真正的系统级置顶窗口**，能压在全屏的新教育平台之上。所以教室端是**网页**：

- 不用打包 exe、不用装东西、不用管理员权限、不用上架
- 一体机上用 Edge 打开一个网址，点一次「启动置顶小窗」即可
- 换电脑只要打开同一个网址

**组成部分**

| 能力 | 做法 |
| --- | --- |
| 强制置顶小窗 | `documentPictureInPicture.requestWindow()` + `createPortal` 把 React 渲染进小窗文档 |
| 当前题号 / 正确率 | 小窗折叠态只显示这两个数，大号字，后排也能看清 |
| 错误人员名单 | **点一下才展开，再点立即收起**；换题自动收起，不会把上一题的名单留在屏幕上 |
| 切题 | 小窗里的 ◀ ▶，或小窗获得焦点时用键盘方向键 |
| 语音播报 | **系统 TTS**（`speechSynthesis` 中文语音），播报前先用 WebAudio 合成「叮咚」提示音，不依赖任何音频素材 |
| 播报浮层 | 收到呼叫后全屏深色浮层显示整句，支持「再播一遍」 |
| 在线状态 | 教室端每 4 秒发心跳，教师端超 12 秒收不到就判定离线 |
| 兜底 | 浏览器不支持 PiP 时，同一份内容以内联浅色面板呈现（`tone="inline"`），功能不丢 |

**跨设备通信**：当前用 `BroadcastChannel` 实现，**同一个浏览器开两个标签页即可完整演示**
（教师端 + 教室端）。接 Supabase 时只需换掉 `src/lib/realtime.ts` 一个文件，调用方一行都不用改。

***REMOVED******REMOVED******REMOVED*** 情绪价值

***REMOVED******REMOVED******REMOVED*** 法定假期与调休

**数据来自官方**：`src/data/holidays.ts` 由 `scripts/fetch-holidays.mjs` 从中国政府网抓取
《国务院办公厅关于XXXX年部分节假日安排的通知》原文并解析生成，**不手工维护**。

```bash
npm run fetch:holidays            ***REMOVED*** 重新抓取 NOTICES 里列出的年份
npm run fetch:holidays 2027 <url> ***REMOVED*** 国务院发布次年安排后追加
```

当前覆盖 **2026 年**（国办发明电〔2025〕7号）：7 个节日 + 6 个调休上班日。
「我的」页会显示数据来源与覆盖年份；缺当前年份时会明确提示并给出更新命令。

**判定规则**（全部按**北京时间**，`beijingNow()`，不依赖设备时区）：

| 日期性质 | 行为 |
| --- | --- |
| `holiday` 法定假期 | 不弹任何窗；工作台首栏显示「祝王老师中秋节快乐！假期要记得好好休息噢。」（清明用「清明安康」） |
| `makeup` **调休上班** | **按工作日对待** —— 早上照常弹欢迎窗、该提醒的上课也提醒 |
| `weekend` 周末 | 首栏显示「今天是周末噢，好好休息吧。」 |
| `workday` 工作日 | 常规流程 |

**假期倒计时**：祝福语下方显示「还有 N 天到中秋节，再坚持一下下。」（30 天内才提，太远就不提了）；
**只剩 3 天以内**时，连「今天完成了」的收尾也换成这句。

**顺带修掉的一个问题**：假期当天原本还会播报上课提醒 —— 法定假期不上课，
提醒和学习日程都按 `dayKind` 屏蔽掉了（调休上班日不受影响）。

***REMOVED******REMOVED******REMOVED*** 交互与实现上的几个坑（都已修）1. **单击立即生效，双击时再回退** —— 而不是等 260 ms 判双击。
   高频录入里每一次点击的延迟都会被放大，宁可让双击时闪一下。
2. **浮层一律走 Portal** —— 页面过渡动画会给 `<main>` 创建层叠上下文，
   浮层的 z-index 会被关在里面、被底部导航盖住导致按钮点不到。
3. **`.btn` 不能设 `flex-shrink: 0`** —— 它会让并排的两个 `w-full` 按钮
   把后一个直接挤出屏幕（"完成"按钮消失）。防换行用 `white-space: nowrap` 就够了。
4. **`useEffect` 不能放在提前 return 之后** —— 否则 Hook 调用顺序在不同渲染路径下不一致。

***REMOVED******REMOVED*** 开发环境注意事项

- `vite.config.ts` 里开了 **`server.watch.usePolling`**。Windows 下编辑器的原子写入
  （先建临时目录再改名替换）会让原生文件监听抛 `EBUSY` 并**静默失效**，
  表现为服务器一直发旧代码、改了不生效、路由对不上。轮询能彻底规避这一类问题。
- `npm run shots` 需要本机 Edge（路径写在 `scripts/shots.mjs` 顶部的 `EDGE`）。
  它会跑完整的端到端流程并截图，**同时收集控制台与页面错误**，任何一步失败都会非零退出。
